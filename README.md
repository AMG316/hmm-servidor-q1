# Evaluación Estocástica de HMM en Monitoreo de Servidores (Estándar Q1)

Este repositorio contiene la implementación reproducible de un Modelo Oculto de Markov (HMM) para inferir la salud de un servidor cloud a partir de series temporales de latencia de red.

## Requisitos y Entorno
- Python 3.10+
- NumPy, Pandas, Matplotlib

## Instalación y Ejecución
```bash
pip install -r requirements.txt
python main_simulation.py
